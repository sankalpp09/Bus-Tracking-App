# 🚌 Bus Tracking App

A React-based Bus Tracking and Ticket Booking Application built to help users track buses, view routes, and book tickets easily.

## 🚀 Features

* Live Bus Tracking (Simulated)
* Route Selection
* Seat Availability
* Crowd Level Display
* Ticket Booking
* Payment UI
* Ticket Generation
* My Tickets Section
* Responsive UI
* Android App Support (Capacitor)

## 🛠 Tech Stack

* React JS
* JavaScript
* Tailwind CSS
* Capacitor (Android)
* HTML & CSS

## 📱 Platform

* Web Application
* Android Application
